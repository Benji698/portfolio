Issu de la logistique et du transport, je me reconvertis vers l'informatique par la voie de l'alternance pour construire les outils que j'utilisais hier sur le terrain.

Après un Baccalauréat STMG puis une Licence 1 Économie, Gestion et Droit à Lyon 2, j'ai découvert le monde professionnel sur le terrain : chauffeur livreur, assistant événementiel chez GEODIS, puis plus de deux ans comme agent de parc automobile chez TEA Lyon à gérer une quarantaine de véhicules par jour.

Ce que j'apporte : l'autonomie et la rigueur procédurale acquises sur le terrain, le respect des délais, et surtout la compréhension du besoin métier derrière l'outil — parce que l'outil, hier, c'était moi qui l'utilisais.

    05 · Veille technologique

    L'IA dans le développement logiciel

    Depuis mon entrée en BTS SIO, je suis l'évolution rapide de l'intelligence artificielle dans le métier de développeur : productivité, qualité du code, nouvelles pratiques et nouveaux risques.

    Sujet principal

    Les assistants de code et le quotidien du développeur

    Les assistants de code basés sur des modèles de langage (LLM) comme GitHub Copilot, Claude Code ou Cursor transforment la manière de programmer : génération de code, explication, refactoring, tests, documentation. Je m'intéresse à leur impact concret sur un projet BTS : gain de temps mesurable, mais aussi qualité, dette technique et dépendance.

    Je suis particulièrement l'évolution de l'agentic coding (agents autonomes capables de lire une base de code, écrire des fichiers et exécuter des commandes), le Model Context Protocol (MCP) qui standardise la connexion des IA à des outils externes, et les bonnes pratiques émergentes : code review systématique du code généré, tests avant de livrer, et attention aux injections de prompt.
